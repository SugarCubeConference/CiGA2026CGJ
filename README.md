## 介绍

一只身患"死亡回归"诅咒的魔法史莱姆，潜入沉睡千年的古老地宫，寻找传说中能解除诅咒的秘药。每一次死亡都会在时空中留下回响，化作重演行动的分身。玩家需要利用死亡、锚点与分身，跨越机关、尖刺与魔法陷阱，在不断回溯中找出逃离地宫的道路。
